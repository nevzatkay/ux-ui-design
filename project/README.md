# Rulebook — Board-game Rules Companion with Source References

**Project goal:** Help a group playing a board/card game investigate a concrete rules question using the correct selected edition, inspect a source passage and make an informed table decision. An unsupported rule answer must be labeled as uncertain rather than guessed.

**Research context:** The only primary user account on record is one anonymised retrospective UNO +2/+4 dispute. Research-use consent for verbatim quotation is not yet confirmed. It is not a live observation or a representative dataset.

## What has and has not been validated

The Figma source navigation and component structure were programmatically checked: main links 4/4, exception entry links 4/4, 12 genuine variants and 23 instances. **These are technical checks only**, not evidence that a player would understand the UI or retrieve a correct official ruling. The first release uses preset content and a sample passage; source indexing, text entry and real rulebook attribution remain future implementation steps.

**Next step that reduces uncertainty:** Obtain consent from three suitable participants, run the Week 08 neutral scenario without verbal walkthrough, record observable behavior and exact quotes separately, then revise and retest the highest-severity issue with a permitted official rules passage.
