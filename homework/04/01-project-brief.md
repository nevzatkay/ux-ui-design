# One-page project brief — Rulebook (Week 4)

**Project / author:** Board-game rules companion with source references · Nevzat Kayıkçı · JWM27Z  
**Focus:** Resolving one disputed card combination **during** a game (initial test: UNO +2 → +4).

| Brief element | Definition |
| --- | --- |
| **Central problem** | During group play, a player cannot confidently determine whether a particular card sequence is allowed, leading to a pause while the group looks up and interprets rules. |
| **Target user** | A rule-checking member of a group game, represented by anonymized P01. No age or device profile is inferred. |
| **Primary task** | Decide if +4 can be played on +2, under the selected official UNO rule edition, and identify the supporting rule passage or an evidence gap. |
| **Organizational goal** | Develop and evaluate a small, verifiable rules-reference companion that helps players decide without unsupported claims. |
| **Constraints** | Mobile-friendly; limited selected games; lawfully usable text-based PDF/Markdown sources; explicit game/edition/expansion scope; accessible text and keyboard interaction; rule evidence visible. |
| **Proposed success criterion** | In a planned test, ≥16/20 answerable tasks produce the correct ruling **and** a supporting passage within 90 s; ≥4/5 unresolved tasks are correctly flagged as unsupported. These are targets, **not results**. |
| **Exclusions** | Running the game, playing as opponent, enforcing penalties, choosing house rules for players, covering all editions/games, and guaranteeing answers absent source evidence. |

## Stakeholder table

| Stakeholder | Need / interest | Design implication |
| --- | --- | --- |
| **Player asking the question (primary)** | Know what move is allowed | Match specific game situation; show clear answer or uncertainty |
| Other players at the table | Understand and verify the ruling | Make evidence legible and shareable, not a black-box assertion |
| Game organizer / host | Keep the game moving fairly | Avoid long detours; never present a guess as an official rule |
| Project designer / evaluator | Show measured progress | Capture task success, timing, citation correctness and gaps |
| Rulebook owners / publishers | Accurate use and attribution | Use permitted sources, preserve edition and cite passages |

**Research evidence:** P01 reported a UNO +2/+4 dispute followed by an online lookup and rule reading. **Assumptions to test:** that citations and edition choice improve decisions without slowing players down; that the MVP is feasible with selected rulebooks.
