# Evidence-based proto-persona and user journey

## Proto-persona — P01, rule-checking player

This task-oriented **proto-persona** is based on one participant account. It does not invent a name, age, occupation or personality.

| Aspect | Description | Evidence |
|---|---|---|
| Situation | Playing UNO with a group while +2/+4 card order is disputed | Participant report |
| Goal | Decide whether the +4 move is allowed | Inferred from the dispute |
| Knowledge | Recognizes the cards but is uncertain about the combination | Inference |
| Behavior | Searches online with group, reads rules, reaches a decision | Participant report |
| Constraint | Needs a ruling for an action in the current game | Task context |
| Risk | An unsupported or edition-inappropriate answer could lead to the wrong move | Assumption |
| Unknown | Feelings, age, device, time pressure, edition, skill level | Not reported |

## Journey: Decide whether +4 can be played on +2 during UNO

| Step | Action | Feeling | Pain point | Opportunity |
|---|---|---|---|---|
| 1. Dispute | Group asks if +4 can follow +2 (reported) | Unknown | Rule is unclear (inferred) | Accept the specific card-combination question |
| 2. Lookup | Group searches the internet (reported) | Unknown | Site and time unknown | Search within selected game and edition |
| 3. Read | Group reads rule text (reported) | Unknown | Relevance of passage not measured | Show a short, inspectable citation |
| 4. Decide | Group decides +4 cannot be played on +2 (reported) | Unknown | Edition and source not verified | Show ruling with source and edition |

**Boundaries:** This is a reconstructed sequence from a short self-report, not an observed or timed workflow. No emotions or exact pain duration were reported. Next study: observe live lookup, ask the participant about feeling at each step and compare source-opening behavior with a prototype.
