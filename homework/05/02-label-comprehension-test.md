### Prompts (repeat unchanged for each tester)
1. “You need to tell the service which game you are playing. Which label would you choose, and why?”
2. “Your game has a newer edition and an expansion pack. Where would you expect to set those?”

4. “You received an answer. Where would you look for the original rule text, and what do you expect to see?”
5. “The service says ‘Cannot verify.’ What do you think that means, and what would you do next?”

**Follow-up for unclear responses:** “What did you expect that label to do?” Avoid suggesting the preferred answer.
