# Reflection — Week 08

## Design inspection (completed)

**Surprising in the previous clickable mock-up:** A screen that visually looks like a citation can still contain unverified placeholder material. Navigation to a sample excerpt is not equal to successful evidence checking; the interface must say so explicitly.

**Useful learning from redesigning:** Semantic color roles make it easier to maintain a high-contrast, consistent primary action and distinct wording for unsupported, missing-detail and source-error states. A clearer answer/status hierarchy supports the core task better than adding extra functions.

**Changes made:** Explicit demonstration status, narrower CTA labels, a more cautious completion message, four visibly separate recovery states, and named Light/Dark color variables, typography and spacing styles.
