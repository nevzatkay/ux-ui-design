## Scope restrictions

The audit uses on-screen textual details, not captured website screenshots. An accessibility manual spot-check of the supplied heading outline was performed; browser keyboard operation, color contrast and actual DOM alt text have **not** been validated. Do not claim these tests were completed when presenting the work.
