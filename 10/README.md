## Presentation scope

A 5–10 minute narrative from a concrete reported rule dispute through research, scoped decision flow, source-aware interface, iterative prototyping, component library and technically verified links. It explicitly distinguishes **primary retrospective research**, **designer review**, **structural verification** and **not-yet-conducted user tests**. It must not claim three users tested it.

## Evidence-based self-reflection

**Strongest available primary evidence:** One anonymous participant reported that their group was uncertain about playing a +4 after a +2 in UNO, searched online, read rule text and then reached a decision. This supports focusing on a **concrete card situation plus readable rule evidence**; it does not demonstrate that our prototype works, nor establish rule correctness.

**Strongest design/technical evidence:** Week 09 structural inspection verified 4/4 main-path navigation targets, 4/4 exception entry targets, 12 component variants and 23 instantiated components. These numbers say the design is connected and componentised, **not** that human users understand it.

**What I would examine further:** Run consented, unguided usability trials with three relevant students; record independent completion, source recognition, recovery and whether participants understand the demo source is not official. Bind a permitted real rulebook to a citation before assessing factual rule correctness or source traceability.

## Optional short portfolio case

**Situation:** A UNO table disputes a special-card interaction. **Evidence:** A participant recalls searching online and reading rules before deciding. **Decision:** Design a narrow edition-aware workflow that exposes a passage alongside an answer and admits missing evidence. **Result so far:** A clickable task prototype and reusable Figma design system with structurally verified navigation; no valid user performance claim yet. **Lesson:** Verifiable source status must be visible to prevent a demo from being mistaken for an official ruling.
